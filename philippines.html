连接菲律宾电脑
用 Paseo 开始工作

这份手册教你两件事：① 远程看到并操作放在菲律宾的 Mac 电脑；② 在自己电脑的浏览器里，让那台 Mac 上的 AI 助手 Claude 帮你干活。不需要技术背景，按顺序一步一步照做即可。

新手必读 ① / 整体介绍

3 分钟看懂整件事

背景：我们要做什么

菲律宾办公室放着两台 Mac 电脑，一台叫 Old，一台叫 New。项目代码和 AI 助手 Claude 都装在这两台电脑上。你人不在菲律宾，所以需要两个工具把它们“搬”到你面前：

工具一Jump ＝ 远程遥控器

把菲律宾 Mac 的屏幕显示在你的电脑上。你动鼠标、敲键盘，那台 Mac 就跟着动，就像你坐在它面前一样。

什么时候用：第一次配置，以及出问题需要检查时。

工具二Paseo ＝ 网页版工作台

在你自己的浏览器里打开一个网页，就能给菲律宾 Mac 上的 Claude 派任务、看结果，不用再盯着远程桌面。

什么时候用：配置完成后的每一天。

记住这一点就够了首次配置和排查问题用 Jump。配对成功后，日常直接打开 Paseo 网页即可，不需要一直开着 Jump。但菲律宾的 Mac 必须一直开机、联网，Paseo 也要一直运行。

整个流程只有四步

第 1 步 / 连接连上远程桌面在 Jump 里选对 Old 或 New第 2 步 / 检查确认那台 Mac 就绪Claude 能回复，Paseo 在线第 3 步 / 配对让浏览器连上它拿到链接，粘贴，输入密码第 4 步 / 工作进入项目开始工作选项目，给 Claude 派任务

第 1～3 步通常只在第一次做；以后每天只需要第 4 步。

一共涉及四个软件

软件大白话装在哪台电脑
Jump Desktop遥控器：用来看到并操作远程桌面你自己的电脑
Jump Desktop Connect接收器：让电脑“允许被遥控”菲律宾 Mac
Paseo工作台：管理项目和 AI 对话菲律宾 Mac 上运行；你用浏览器打开网页即可
Claude CodeAI 助手：读代码、改代码、跑测试菲律宾 Mac（要在那台电脑上安装并登录）
你自己的电脑上需要装什么？只需要装 Jump Desktop 一个软件。Paseo 用浏览器打开网页就行，不用安装。

新手最容易卡住的地方，就是把密码填错了位置。整个流程里有四套互相独立的账号密码，它们互不通用：

屏幕上出现什么应该填哪一套说明
Jump 的登录页面公司授权给你的 Jump 账号用来登录“遥控器”软件。

  • 不要把密码、配对链接、二维码、邮件验证码、授权链接发到公共群、群公告、公共文档或代码仓库里。

菲律宾电脑安装 Connect

谁来做
菲律宾现场同事（人要在电脑旁边）
在哪台电脑
菲律宾的 Mac
做完的效果
这台 Mac 允许被远程连接

这一节的目的：给菲律宾 Mac 装上“被控端”软件 Connect。首次安装需要输入管理员密码、打开系统权限，所以必须有人在电脑旁边操作；完成后再交给远程同事接手。

1下载 Connect

  1. 在菲律宾 Mac 上打开 Safari 或 Chrome 浏览器。
  2. 打开 Jump 官方下载页。
  3. 在 Mac 区域点击 Connect for macOS（见下图绿色框）。

找不到的话，也可以直接点这个官方 Connect 下载入口。

别下错下载页上有 Viewer 和 Connect 两种。这台菲律宾 Mac 要装的是 Connect。

2安装并打开

  1. 下载完成后，在 Downloads（下载）文件夹里找到安装包并双击打开。Mac 上通常是一个 .dmg 文件。
  2. 运行里面的安装程序，按窗口提示一路完成。
  3. 如果弹窗要求管理员密码，由现场同事输入这台 Mac 的管理员密码。
  4. 安装完成后，在 Applications（应用程序）里打开 Jump Desktop Connect。
怎么确认装对了
  • 装对了：打开后能看到“添加远程访问用户”“屏幕共享”或“权限检查”之类的入口。
  • 装错了：看到 Automatic Setup / Manual Setup，或者让你填写 RDP / VNC 地址。这通常说明你打开的是控制端 Jump Desktop，请改为打开 Connect。

3打开 macOS 系统权限

Mac 默认不允许别的软件看屏幕、动鼠标，所以要手动打开几个开关。

  1. 在 Connect 弹出的权限向导里点 Continue，按提示打开系统设置。
  2. 进入 System Settings → Privacy & Security（系统设置 → 隐私与安全性）。
  3. 按下表找到每一项，把 Jump Desktop Connect 的开关打开。如果开关是灰色点不动，先请管理员解锁。
  4. 设置完回到 Connect 继续。如果系统要求退出并重新打开 Connect，按提示操作。
权限名称有什么用怎么处理
Screen Recording
屏幕录制		让远程的人能看到桌面打开 Connect 的开关
Accessibility
辅助功能		让远程的人能控制鼠标键盘打开 Connect 的开关
Remote Desktop
远程桌面		macOS 14 及之后版本的无人值守权限手动检查，确认开关已打开
Microphone
麦克风		按官方向导用于远程音频不需要声音的话，按向导跳过即可
几个小提示
  • 不同 macOS 版本的名称可能略有不同，例如显示为“屏幕与系统音频录制”，以你当前看到的向导为准。
  • “远程桌面”权限的状态需要自己手动确认一遍。
  • 如果只开了屏幕录制、没开辅助功能，结果会是：能看见桌面，但鼠标键盘动不了。
  • 想重新打开权限向导：点 Connect 的齿轮图标 → Diagnostics → Check macOS Permissions。

4让电脑保持长期在线

  • 点 Connect 的齿轮图标，在 General 里确认 Start Jump Desktop when my computer starts（开机自动启动）是打开的。
  • 电脑一直插着电源、连着网络。
  • 关闭电脑的自动睡眠。显示器可以熄屏，没有影响。
  • 如果是笔记本，不要直接合上盖子，否则会进入休眠。
关于重启和 FileVault如果这台 Mac 开了 FileVault（磁盘加密），重启后可能需要现场的人输入密码才能进入系统。不要为了省事直接关闭磁盘加密。正确做法是：趁现场同事还在，测试一次“重启后能否恢复远程连接”。

✓ 做完后，把这句话发给远程同事“Connect 已安装、系统权限已开启，电脑保持接电和联网，请提供授权方式。”

这一节的目的：在你自己的电脑上装“遥控器”软件 Jump Desktop。注意，只装 Connect 是不行的，Connect 是给“被遥控”的电脑用的。

1打开下载页，选 Viewer

  1. 打开 Jump 官方下载页。
  2. 你的电脑是 Mac：选择 Viewer for macOS，然后看第 2 步。
  3. 你的电脑是 Windows：先切换到 Windows 页面，选择 Viewer for Windows，然后看第 3 步。

2如果你用 Mac

  1. 在 Viewer 菜单里选择 Jump Desktop Mac for Teams（团队版）。
  2. 打开下载的安装包，按提示安装。
  3. 如果出现一个“拖拽安装”的窗口，把 Jump Desktop 图标拖到 Applications 文件夹里。
  4. 从 Applications（应用程序）打开 Jump Desktop。

也可以按公司的采购方式使用 Mac App Store 版本。

看到 “Free 14 Days” 不用担心
  • 菜单里的 Free 14 Days 只是一个下载选项，不代表公司的团队授权只有 14 天。
  • 公司已经有团队的话，直接用公司现有团队的账号和授权。
  • 不需要为了接入自己新建团队，也不需要自己花钱购买。
  • 实际能用哪些功能，以公司的套餐和席位为准。

3如果你用 Windows

  1. 在官方下载页切换到 Windows。
  2. 下载 Viewer for Windows。
  3. 运行下载的安装程序，按提示完成。
  4. 打开 Jump Desktop。
别下错不要选 Connect for Windows。那个是把你自己的 Windows 电脑变成“被遥控”的电脑。

4登录 Jump 账号

  1. 打开 Jump Desktop，找到 Automatic Setup 或登录入口。
  2. 登录公司授权给你的 Jump 账号。
  3. 如果跳转到浏览器登录，在浏览器里登录完再回到 Jump Desktop。

还没有账号？按公司流程注册，并接受团队邀请。

不要碰 Manual Setup如果打开的是 Manual Setup（手动设置），不要随便填写远程 IP、RDP 或 VNC。我们团队的正常方式是：登录获授权的账号，然后从电脑列表里选择目标电脑。

5等待授权

能登录 Jump，不代表你已经有权限连接菲律宾电脑。如果电脑列表里没有 Old 或 New，说明还没被授权。继续看安装 C，或者请管理员通过现有团队给你分配访问权。

✓ 完成标准自己的电脑能正常打开 Jump Desktop，并且已经登录了预期的 Jump 账号。

授权并测试首次连接

谁来做
远程操作人员和菲律宾现场同事一起配合
在哪台电脑
两边都要操作
做完的效果
不需要现场点同意，你就能连上并操作那台 Mac

这一节的目的：让菲律宾 Mac “认识”你的 Jump 账号，允许你连接。

先选一条路，只做一条授权有两种方式，公司用哪种就做哪种，不用两种都做。不确定用哪种？问管理员。已经授权过的电脑可以直接连接，跳到下面的“测试第一次连接”。

方式一：公司已经有 Jump 团队

这种方式主要由管理员操作，你只需要配合：

  1. 管理员：把菲律宾 Mac 加入公司现有团队，并把你的账号加入“允许访问这台电脑”的 Access Group（访问组）。
  2. 你：接受团队邀请。
  3. 你：在 Jump Desktop 里登录被授权的账号，等电脑出现在列表里。
列表里没有目标电脑？加入团队不代表自动能连所有电脑。请管理员检查访问组和远程访问席位。不要自己新建团队，也不要把已经在公司团队里的电脑移走。

方式二：使用个人 Connect Code

简单说：你把一串代码发给现场同事，对方在菲律宾 Mac 上输入，就完成授权。

  1. 你（远程操作人员）：登录 Jump Dashboard，在 Home 页的 Your Connect Codes 里复制自己的 Connect Code。如果没有，就创建一个 Personal Connect Code。
  2. 你：把这串代码和你的账号名称发给现场同事。
  3. 现场同事：在菲律宾 Mac 上打开 Connect → Add a remote access user → 进入浏览器登录入口 → Give remote access to someone else，输入收到的代码。
  4. 现场同事：核对页面上显示的账号名称是不是对的，然后点 Allow。如果页面要求先登录，现场同事用自己获准使用的 Jump 账号登录即可。不需要让远程同事提供 Jump 密码。
  5. 双方一起确认：Connect 里出现了被授权的用户；你在 Jump Desktop 用同一个账号登录后，能看到这台 Mac。
两种 Connect Code 的区别
  • 团队的 Connect Code：用来把一台电脑加入团队。
  • 个人的 Connect Code：用来给某一个人开远程访问权限。
两者用途不同，管理员发代码时应该写明是哪一种。

授权完成后：测试第一次连接

1连接并输入 Mac 的系统密码

  1. 在自己的 Jump Desktop 里点击 Old 或 New。
  2. 如果弹出用户名和密码，输入菲律宾 Mac 的系统用户名和密码（不是 Jump 账号）。

不知道 Mac 的用户名？请现场同事在那台 Mac 的 Terminal 里输入 whoami 再按回车，显示出来的就是用户名。

屏幕上出现什么填哪一套
Jump 登录获授权的 Jump 账号
连接 Mac 时的系统登录菲律宾 Mac 的本地用户名与系统密码
Paseo Password该主机单独设置的 Paseo 访问密码

2确认“看得见”也“动得了”

  1. 看 Jump 窗口的标题，确认连的是正确的那台（Old 或 New）。
  2. 移动鼠标，打开一个普通窗口，输入几个字。
  3. 画面正常、键盘能打字，就说明没问题。

如果每次连接都还要现场同事点批准，请检查：长期访问用户有没有加上、Remote Desktop 等权限有没有打开、团队策略是否允许。

  1. 确认 Host 显示 Online（在线）。
  2. 打开一个分配给你的项目，确认能看到工作区。
现在可以关掉 Jump 了连接成功后，可以关闭 Jump 远程窗口，以后直接用 Paseo 网页。但菲律宾的 Mac 和上面的 Paseo 服务仍然要保持运行。

第 5 章 / 开始工作

选项目，让 Claude 干活

谁来做
远程操作人员（你自己）
在哪台电脑
自己的电脑，Paseo 网页
做完的效果
Claude 完成任务，你检查并记录结果

这是你每天都会用到的一章。顺序是：选主机 → 选项目 → 开工作区 → 选 Claude → 说清任务 → 检查结果。

1先选主机，再选项目

  1. 先确认当前的 Host 是 Old 还是 New。
  2. 再打开侧边栏的 Project（项目）。

建议把项目标签命名成“Old | 项目名”和“New | 项目名”，一眼就能分清。如果两台电脑上有同名项目，要看它的 Host 徽章和实际目录来区分。

2打开或新建工作区

  • 继续之前的任务：打开对应的 Workspace（工作区）。
  • 开始新任务：用该项目的“新建 Workspace”入口。

如果任务需要独立分支：要实际确认这个工作区有没有创建 Git worktree，以及当前的目录和分支是什么。不要只看名字就下判断。

3选择 Claude 和模型

  1. 打开 Agent 会话。
  2. provider 选择 Claude。
  3. 在模型选择器里，选一个当前账号实际可用的模型。

列表里有哪些模型，取决于远程 Claude Code 的版本、账号和服务状态，会随时间变化，所以手册里不写死具体型号。

4把任务说清楚

给 Claude 的任务说明里，最好包含这四样：

  • 哪个项目
  • 以哪个分支为基准
  • 改动范围是什么
  • 希望最后产出什么
涉及真钱、真账号时如果任务涉及真实付款、真实账号，或者有无法自动完成的验证，要明确要求 Claude 停下来，告诉你需要人工做哪些步骤。

不知道怎么写？直接复制这两段提示词

提示词一：第一次进项目时，先让 Claude 检查环境

任务提示词

请先确认当前主机、工作目录、Git 分支和未提交改动，检查项目使用的 Git 提交身份与 GitHub 账号。只检查，不修改配置，也不要输出密钥。确认环境后，阅读项目说明并列出启动和测试步骤。

提示词二：让 Claude 测试代码改动

任务提示词

请对比当前分支与指定基准分支的代码改动，列出受影响功能和测试计划。按项目约定执行检查，记录通过、失败和未测试项，并保存测试报告及必要截图。涉及真实付款、账号验证或外部发布时先由我处理。

5检查结果并交接

  • 查看 diff（代码改动对比）、执行结果和报告。
  • 要求 Claude 写明测试用的设备、环境、测试范围和证据。
  • 记下这次用的工作区和分支，方便下次接着做。
两个容易误会的地方
  • Claude 说“完成了”，不等于真机测试通过了。一定要看它给出的证据。
  • 关闭网页不等于停止任务。想停止，要用会话里的“停止”操作。想让任务继续跑，要确认远程服务在线：不要退出 Paseo，不要让 Mac 休眠或关机。

第 6 章 / 团队协作

团队协作与 GitHub 身份

谁需要看
所有会在共享电脑上改代码的人
在哪里
团队共享环境
目的
多人共用一台电脑时不互相干扰

菲律宾的 Mac 是多人共用的。这一章讲怎样避免“两个人改同一个文件夹”和“用错账号提交代码”。

共享电脑的四条约定（所有人必读）

  • 操作 Jump 桌面前，先和正在使用的人打声招呼，避免两个人同时抢鼠标键盘。
  • 开始任务前先检查有没有未提交的改动。不要清理别人的工作区。
  • 重启 Mac、重启 Paseo 或更换 Claude 登录账号之前，先确认没有任务正在运行。
  • 使用公司批准的 Claude 账号和授权方式。Paseo 不会改变账号本身的使用条款和额度。

一个任务一个工作区

  • 业务代码建议统一放在 ~/Developer/ 下面。
  • 不同人员或用途，使用清晰的项目标签。
  • 多人同时改同一个仓库时，每人用自己的分支和 worktree。
不要这样做不要两个人同时在同一个工作目录里切换分支，或同时执行会改动文件的任务。

目录可以这样组织（这只是建议，不代表两台电脑当前的目录完全一样）：

目录示例
~/Developer/kumu-flutter
~/Developer/kumu-android
~/Developer/worktrees/<项目>-<负责人>-<任务>

分开文件夹 ≠ 别人看不到

不同的文件夹和 worktree 可以减少文件冲突和分支冲突，但不是权限隔离：

  • 在同一个 macOS 用户下，Paseo 和 Claude 通常能访问这个用户可以读到的其他项目。
  • 共用同一台主机的人，也可能看到彼此的会话。

如果确实要求“前端同事不能看到后端项目或操作记录”，需要另外部署独立的系统用户与服务，或者使用独立的主机。不要把公共的 Paseo 当作私密项目空间。

提交代码时，“署名”和“实际账号”是两回事

项目决定什么由什么决定
Git 提交身份commit 上显示的姓名和邮箱（署名）user.name 和 user.email
GitHub 操作账号push、拉取仓库、PR 评论实际用的是谁的账号实际使用的 SSH 密钥、令牌或 gh 登录身份

所以只改 user.name，并不能防止“评论是用错误的账号发出去的”。两样都要检查。

在当前项目的终端里执行下面四条命令，可以看到这两样现在分别是什么：

远程 Mac · Terminal
git config --show-origin --get user.name
git config --show-origin --get user.email
git remote -v
gh auth status
命令它告诉你什么
前两条 git config提交时署名的姓名和邮箱，以及这个设置写在哪个文件里
git remote -v这个项目连接的是哪个远程仓库
gh auth statusgh 工具当前登录的是哪个 GitHub 账号
共享电脑上要特别小心
  • 不要把令牌或私钥发给别人。
  • 不要随意执行 gh auth switch。它会改变这台电脑上所有项目使用的默认账号，影响到其他人。
  • 正确做法：由管理员为每个项目配置对应的 SSH 别名，以及独立的 gh 配置目录或启动环境。

出问题了怎么办

先在下面的表里找到你遇到的现象，再点开对应的问题，按顺序一项一项检查。

你看到的现象先检查什么
Jump 列表里没有电脑，或连不上账号和授权是否正确；菲律宾 Mac 是否开机联网
Paseo 显示离线或一直 Connecting先用 Jump 连上去，看 Paseo 有没有在运行
Password required 或密码错误是不是用错了密码（Old 和 New 不同）
没有模型可选，Claude 报错远程 Mac 的 Terminal 里 claude 能不能回复
项目不见了是不是选错了主机（Old / New）

点击下面的问题可以展开详细步骤：

Jump 看不到电脑或连接不上

按顺序检查：

  1. 登录的 Jump 账号对不对。
  2. 这个账号有没有这台电脑的访问权限。
  3. 团队套餐或席位状态是否正常。
  4. 菲律宾 Mac 有没有电、有没有网络。
  5. Connect 是否在运行、系统权限是否完整。

不要只因为连接失败，就认定是需要续费。

如果 Mac 关机或重启后，停在 FileVault 解锁界面，可能需要现场的人完成开机和登录。另外，显示器熄屏和电脑休眠不一样：熄屏没有影响，休眠或断网才会导致连不上。

Paseo 离线或一直 Connecting
  1. 先通过 Jump 连上去，检查电脑是否在线、Paseo 是否在运行。
  2. 再看 Host 和 Relay 的状态。

Jump 正常，不代表 Paseo 一定正常，这是两个独立的东西。

需要重启服务时，先确认当前的任务状态。不要随手点“重启并关闭终端”，那样会中断其他人正在进行的工作。

提示 Password required 或密码错误
  • 确认用的是目标主机的 Paseo 密码。Old 和 New 的密码不同。
  • 主机已经添加，但没有输入密码的地方：按第 4 章的方法移除后重新添加。
  • 忘记密码：交给管理员在远程 Mac 上重新设置，保存后重启服务（见安装 E）。
没有模型可选 或 Claude 显示错误
  1. 先点开 provider 的错误详情，看具体写了什么。
  2. 在运行 Paseo 服务的同一个 Mac 用户下，打开 Terminal 执行 claude --version。
  3. 再执行 claude 启动它，确认能正常回复。
  4. 如果终端里也不行，依次排查：账号授权、网络、Paseo 查找 CLI 的路径。
  5. 终端里正常之后，再考虑重启 Paseo。

不要反复退出并登录别人的 Claude 账号。

同事在自己电脑安装后没有模型

先问清楚他想做的是哪一种：

  • 想连接菲律宾主机：只需要配对正确的 Host，自己的电脑不用装 Claude。
  • 想把自己的电脑当作 Host：必须在自己的电脑上安装并登录 Claude Code。

只安装 Paseo，不会自动获得模型服务。

项目不见了 或结果出现在另一台电脑

逐项核对：Host（哪台主机）→ Project（哪个项目）→ Workspace（哪个工作区）→ 实际路径 → 分支。

两个 Host 的项目可能同时出现在侧边栏里。名字相似，不能证明是同一个目录。

不要为了找项目而重置配置。

向管理员反馈时附这些信息

把下面这些一次说清楚，管理员能更快帮你解决：

  • 是哪台主机：Old 还是 New
  • 问题发生的时间
  • 页面上的错误原文
  • 通过 Jump 能不能连上
  • Claude 在终端里能不能用
  • 相关截图

截图之前，先遮住配对链接、二维码、密码、令牌和无关的私密信息。

新增一台菲律宾 Mac：按顺序做五件事

  1. 保证电脑长期在线。保持接电和稳定的网络；关闭自动睡眠，允许显示器熄屏。笔记本要注意合盖可能会休眠。
  2. 装好 Jump 两端。在远程 Mac 安装 Jump Desktop Connect，完成系统要求的录屏、辅助功能等权限；在操作端安装 Jump Desktop。详见安装 A、安装 B。
  3. 分配远程访问权限。用现有的公司团队或账号分配权限，并测试无人值守连接。是否需要付费，以实际套餐和席位为准。详见安装 C。
  4. 装好 Claude 和 Paseo。从官方来源安装并初始化 Claude Code 终端版，验证真实请求成功之后，再安装和打开 Paseo。详见安装 D。
  5. 设密码、发链接。配置 Paseo 的远程连接或 Relay，设置访问密码，重启生效，再把链接交给获得授权的使用者。详见安装 E和第 3 章。

Paseo 密码维护

请按安装 E：设置与维护 Paseo 访问密码逐步操作，里面包含命令路径检查、交互输入、单独重启和浏览器验证。

一条一条执行不要一次复制多条命令一起粘贴。每一条都要看到结果、确认保存成功，再执行下一条。

日常维护

  • 定期检查磁盘空间、供电、网络，以及开机后各项服务的状态。
  • 更新 Claude Code 之后，验证终端里还能正常使用。
  • 更新由 Paseo Desktop 管理的 daemon 时：在目标 Mac 上更新 Paseo Desktop，然后再做一次连接和模型检查。
