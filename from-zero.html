从零开始
远程用一台 Mac 和 Claude 工作

这份手册带你从什么都没装开始，搭好一套远程工作环境：① 能远程看到并操作另一台 Mac；② 能在自己电脑的浏览器里，让那台 Mac 上的 AI 助手 Claude 帮你干活。不需要技术背景，按第 1 步到第 8 步的顺序照做即可。

打开 Jump ↗打开 Paseo ↗

本文件不包含任何账号、密码或配对链接。

新手必读 ① / 整体介绍

3 分钟看懂整件事

我们要搭的是什么

整套环境里有两台电脑：

电脑一远程电脑

一台一直开着机、连着网的 Mac。项目代码和 AI 助手 Claude 都装在它上面，真正干活的是它。它可以放在办公室、机房或家里。

电脑二自己的电脑

你手边正在用的电脑，Mac 或 Windows 都可以。你通过它去指挥远程电脑，人在哪里都行。

要让自己的电脑能指挥远程电脑，需要两个工具：

工具一Jump ＝ 远程遥控器

把远程电脑的屏幕显示在你的电脑上。你动鼠标、敲键盘，远程电脑就跟着动，就像你坐在它面前一样。

什么时候用：第一次搭建，以及出问题需要检查时。

工具二Paseo ＝ 网页版工作台

在你自己的浏览器里打开一个网页，就能给远程电脑上的 Claude 派任务、看结果，不用再盯着远程桌面。

什么时候用：搭好之后的每一天。

记住这一点就够了搭建和排查问题用 Jump。配对成功后，日常直接打开 Paseo 网页即可，不需要一直开着 Jump。但远程电脑必须一直开机、联网，上面的 Paseo 也要一直运行。

一共要装四个软件

软件大白话装在哪台电脑
Jump Desktop Connect接收器：让电脑“允许被遥控”远程电脑
Jump Desktop遥控器：用来看到并操作远程桌面自己的电脑
Claude CodeAI 助手：读代码、改代码、跑测试远程电脑（要在上面安装并登录）
Paseo工作台：管理项目和 AI 对话远程电脑上安装运行；自己的电脑用浏览器打开网页即可
自己的电脑上需要装什么？只需要装 Jump Desktop 一个软件。Paseo 用浏览器打开网页就行，不用安装。

整个搭建过程分三段、八步

阶段包含哪几步做完能干什么
第一段：打通远程桌面第 1、2、3 步在自己的电脑上看到并操作远程电脑
第二段：装好 AI 和工作台第 4、5 步远程电脑上 Claude 能回复，Paseo 在线并有密码保护
第三段：连上浏览器开始工作第 6、7、8 步在自己的浏览器里给 Claude 派任务

这八步只需要做一次。以后每天只用到第 8 步。

手册里的说法意思
远程电脑被远程连接的那台 Mac，项目和 Claude 都在它上面。
自己的电脑你手边正在用的电脑，Mac 或 Windows 都可以。
现场的人能直接摸到远程电脑的人。如果远程电脑就在你手边，这个人就是你自己。
使用者通过网络使用远程电脑的人。
管理员负责分配账号、密码、权限的人。自己一个人搭建的话，管理员也是你自己。

关于 Jump

名词意思
控制端
Viewer / Jump Desktop		“遥控器”那一端的软件，装在你自己的电脑上。
被控端
Connect		“被遥控”那一端的软件，装在远程电脑上。
Connect Code一串授权代码。在远程电脑的 Connect 里输入它，就等于“允许这个人远程连我”。
无人值守不需要现场有人点“同意”，随时都能连上。这是我们最终要达到的状态。
团队 / 席位 / Access Group公司在 Jump 购买的团队套餐。“席位”是可用名额，“Access Group（访问组）”决定谁能连哪台电脑。

关于 Paseo 和 Claude

名词意思
Host（主机）Paseo 里对“一台运行着 Paseo 的电脑”的称呼。在这份手册里，主机就是你的远程电脑。
配对
Pair device		让你的浏览器和某台主机“认识”一下。配对之后，浏览器才能连上那台主机。
配对链接配对用的一串网址，相当于一把钥匙，要像密码一样保管。
RelayPaseo 的远程连接方式。开启后，你和远程电脑不在同一个网络里也能连上。
daemonPaseo 在后台默默运行的服务程序。“重启 daemon”就是把这个后台服务重启一下。
Claude Code 终端版在 Terminal 里运行的 Claude。它和“Claude 桌面 App”是两个东西，要分别登录。
provider / 模型provider 是“由谁提供 AI”，这里选 Claude。模型是 Claude 的具体型号，从下拉列表里选一个能用的即可。
Agent 会话你和 Claude 的一次对话任务。

关于项目和代码

名词意思
Terminal（终端）Mac 自带的一个 App，黑底或白底的窗口，在里面输入一行文字命令再按回车，电脑就会执行。打开方法：按 Command + 空格，输入 Terminal，按回车。
Project（项目）一个放代码的文件夹。
Workspace（工作区）在某个项目里，为一件具体任务开的工作空间。一个任务一个工作区。
分支Git 的功能。可以理解成代码的“一份草稿”，改好了再合并回正式版本。
worktreeGit 的功能。给同一个项目再开一个独立的文件夹，这样两个人各改各的，不会互相打架。
FileVaultMac 的磁盘加密功能。开启后，电脑重启后可能需要有人在现场解锁；能否远程恢复取决于配置，应提前实际验证一次。

四套账号密码，千万别混

新手最容易卡住的地方，就是把密码填错了位置。整个流程里有四套互相独立的账号密码，它们互不通用：

屏幕上出现什么应该填哪一套说明
Jump 的登录页面你的 Jump 账号用来登录“遥控器”软件。
连接远程电脑时要求用户名和密码远程电脑的系统用户名和密码就是那台 Mac 的开机密码。不要把 Jump 邮箱填成 Mac 用户名。
Paseo 里出现 Password / Password required这台主机的 Paseo 访问密码在第 5 步由你自己设置。有多台远程电脑时，每台分别设置、分别保管。
Terminal 里 Claude 要求登录Claude 账号在公司使用时，用公司批准的账号和授权方式。
安全守则
  • 配对链接和二维码等同于密码，同样要保密。
  • 不要把密码、配对链接、二维码、邮件验证码、授权链接发到公共群、群公告、公共文档或代码仓库里。
  • 截图发给别人之前，先把上面这些信息遮住。

第 1 步 / 打通远程桌面

远程电脑安装 Connect

谁来做
现场的人（要在远程电脑旁边）
在哪台电脑
远程电脑
做完的效果
这台 Mac 允许被远程连接

这一步的目的：给远程电脑装上“被控端”软件 Connect。首次安装需要输入管理员密码、打开系统权限，所以必须有人在电脑旁边操作。

现场的人只需要做三件事
  1. 安装 Connect 并打开系统权限（本节第 1 到第 4 小步）。
  2. 把临时访问链接发给远程的人（本节第 5 小步）。
  3. 对方发起连接时，点一下“允许”。
之后的长期授权、安装 Paseo、设置密码等全部配置，都由远程的人连上来完成，现场的人不需要懂这些。

如果远程电脑就在你自己手边，第 5 小步可以跳过。

1下载 Connect

  1. 在远程电脑上打开 Safari 或 Chrome 浏览器。
  2. 打开 Jump 官方下载页。
  3. 在 Mac 区域点击 Connect for macOS（见下图绿色框）。

找不到的话，也可以直接点这个官方 Connect 下载入口。

别下错下载页上有 Viewer 和 Connect 两种。远程电脑要装的是 Connect。

2安装并打开

  1. 下载完成后，在 Downloads（下载）文件夹里找到安装包并双击打开。Mac 上通常是一个 .dmg 文件。
  2. 运行里面的安装程序，按窗口提示一路完成。
  3. 如果弹窗要求管理员密码，输入这台 Mac 的管理员密码。
  4. 安装完成后，在 Applications（应用程序）里打开 Jump Desktop Connect。
怎么确认装对了
  • 装对了：打开后能看到“添加远程访问用户”“屏幕共享”或“权限检查”之类的入口。
  • 装错了：看到 Automatic Setup / Manual Setup，或者让你填写 RDP / VNC 地址。这通常说明你打开的是控制端 Jump Desktop，请改为打开 Connect。

3打开 macOS 系统权限

Mac 默认不允许别的软件看屏幕、动鼠标，所以要手动打开几个开关。

  1. 在 Connect 弹出的权限向导里点 Continue，按提示打开系统设置。
  2. 进入 System Settings → Privacy & Security（系统设置 → 隐私与安全性）。
  3. 按下表找到每一项，把 Jump Desktop Connect 的开关打开。如果开关是灰色点不动，先用管理员身份解锁。
  4. 设置完回到 Connect 继续。如果系统要求退出并重新打开 Connect，按提示操作。
权限名称有什么用怎么处理
Screen Recording
屏幕录制		让远程的人能看到桌面打开 Connect 的开关
Accessibility
辅助功能		让远程的人能控制鼠标键盘打开 Connect 的开关
Remote Desktop
远程桌面		macOS 14 及之后版本的无人值守权限手动检查，确认开关已打开
Microphone
麦克风		按官方向导用于远程音频不需要声音的话，按向导跳过即可
几个小提示
  • 不同 macOS 版本的名称可能略有不同，例如显示为“屏幕与系统音频录制”，以你当前看到的向导为准。
  • “远程桌面”权限的状态需要自己手动确认一遍。
  • 如果只开了屏幕录制、没开辅助功能，结果会是：能看见桌面，但鼠标键盘动不了。
  • 想重新打开权限向导：点 Connect 的齿轮图标 → Diagnostics → Check macOS Permissions。

4让电脑保持长期在线

  • 点 Connect 的齿轮图标，在 General 里确认 Start Jump Desktop when my computer starts（开机自动启动）是打开的。
  • 电脑一直插着电源、连着网络。
  • 关闭电脑的自动睡眠。显示器可以熄屏，没有影响。
  • 如果是笔记本，不要直接合上盖子，否则会进入休眠。
关于重启和 FileVault如果这台 Mac 开了 FileVault（磁盘加密），重启后可能需要现场的人输入密码才能进入系统。不要为了省事直接关闭磁盘加密。正确做法是：趁现场还有人，测试一次“重启后能否恢复远程连接”。

5把临时访问链接发给远程的人

到这里，远程的人还连不上这台电脑。先给对方一条临时链接，让对方连上来接手后面的配置。

  1. 在 Connect 里找到屏幕共享链接，是一条 jumpto.me/… 开头的网址。
  2. 复制它，通过私密渠道发给要接手的人。
  3. 留在电脑旁边。对方打开链接发起连接时，屏幕上会弹出请求，点“允许”。
先别离开临时链接每次连接都要现场点允许。在远程的人配置好长期访问、并验证通过之前，请保持可联系。

✓ 完成标准Connect 已安装并能打开，系统权限已开启，电脑保持接电和联网；临时访问链接已经发给远程的人。

官方参考：下载页面 · macOS 权限 · 无人值守

自己的电脑安装 Jump（控制端）

谁来做
使用者（你自己）
在哪台电脑
自己的 Mac 或 Windows 电脑
做完的效果
Jump Desktop 能打开，并已登录你的 Jump 账号

这一步的目的：在你自己的电脑上装“遥控器”软件 Jump Desktop。注意，只装 Connect 是不行的，Connect 是给“被遥控”的电脑用的。

1打开下载页，选 Viewer

  1. 打开 Jump 官方下载页。
  2. 你的电脑是 Mac：选择 Viewer for macOS，然后看下面的“如果你用 Mac”。
  3. 你的电脑是 Windows：先切换到 Windows 页面，选择 Viewer for Windows，然后看下面的“如果你用 Windows”。

2如果你用 Mac

  1. 在 Viewer 菜单里选择要下载的版本。团队使用者选 Jump Desktop Mac for Teams（团队版）。
  2. 打开下载的安装包，按提示安装。
  3. 如果出现一个“拖拽安装”的窗口，把 Jump Desktop 图标拖到 Applications 文件夹里。
  4. 从 Applications（应用程序）打开 Jump Desktop。

也可以使用 Mac App Store 版本。

关于 “Free 14 Days”
  • 菜单里的 Free 14 Days 只是一个下载选项，不等于长期授权。
  • 公司已经有 Jump 团队的话，直接用公司现有团队的账号和授权，不需要自己新建团队，也不需要自己购买。
  • 实际能用哪些功能，以套餐和席位为准。

3如果你用 Windows

  1. 在官方下载页切换到 Windows。
  2. 下载 Viewer for Windows。
  3. 运行下载的安装程序，按提示完成。
  4. 打开 Jump Desktop。
别下错不要选 Connect for Windows。那个是把你自己的 Windows 电脑变成“被遥控”的电脑。

4登录 Jump 账号

  1. 打开 Jump Desktop，找到 Automatic Setup 或登录入口。
  2. 登录你的 Jump 账号。
  3. 如果跳转到浏览器登录，在浏览器里登录完再回到 Jump Desktop。

还没有账号？公司有团队的，按公司流程注册并接受团队邀请；否则按 Jump 官方流程注册。

不要碰 Manual Setup如果打开的是 Manual Setup（手动设置），不要随便填写远程 IP、RDP 或 VNC。这份手册用的方式是：登录账号，然后从电脑列表里选择远程电脑。

这时电脑列表里还看不到远程电脑，是正常的。能登录 Jump，不代表已经有权限连接那台电脑，授权在下一步做。

✓ 完成标准自己的电脑能正常打开 Jump Desktop，并且已经登录了预期的 Jump 账号。

第 3 步 / 打通远程桌面

授权并第一次连上

谁来做
使用者和现场的人一起配合
在哪台电脑
两台都要操作
做完的效果
不需要现场点同意，就能连上并操作远程电脑

这一步的目的：让远程电脑“认识”你的 Jump 账号，允许你连接。

先看全貌：从“临时接手”到“随时能连”一共五步

  1. 现场的人安装 Connect。打开屏幕录制、辅助功能、Remote Desktop 等权限，电脑保持接电、联网、不休眠。这一步就是第 1 步。
  2. 现场的人把临时访问链接发给你。你打开链接发起连接，对方点“允许”，你就可以先接手操作。
  3. 配置长期访问权限。用个人 Connect Code 或公司团队授权，二选一。
  4. 确认电脑出现在你的电脑列表里。用获授权的 Jump 账号登录控制端，能看到这台电脑。有多台远程电脑时，名称要能一眼分清。
  5. 断开临时连接，再从电脑列表重新连接。验证不再需要现场的人点同意。
一句话分清两种连接
  • 临时链接（jumpto.me/…）：只负责让你第一次接手，每次都要现场的人点允许。
  • 长期授权：电脑加进你的电脑列表，以后随时能连，不需要现场有人。
只把临时链接收藏起来，不等于完成了长期访问配置。

第一阶段：先用临时链接接手

这是推荐的做法：现场的人只负责发链接和点允许，后面的全部配置由你在远程桌面里完成，对方不需要懂 Jump。只有远程电脑就在你手边，或者现场的人自己会做第二阶段的操作时，才可以跳过这一阶段。

接手之后，能不能让 AI 帮你配置？要看条件。Jump 连上了，不代表 AI 工具就自动能操作远程桌面。
  • 你用的 AI 工具已经配置了电脑操作能力，并且获得了授权：可以让它协助操作 Jump 远程窗口，完成剩下的配置（长期授权、安装 Paseo 等）。
  • 否则：按本手册一步步手动完成。
无论哪种情况，输入密码、点击授权这类步骤，建议由你本人操作。
  1. 现场的人：在远程电脑的 Connect 里找到屏幕共享链接，复制这条 jumpto.me/… 链接，发给要接手的人。第 1 步里已经发过的，直接用那一条。
  2. 你：在自己的电脑上打开这条链接，发起连接。
  3. 现场的人：在远程电脑上点击“允许”。
  4. 你：看到远程桌面后，移动鼠标、输入几个字，确认能操作。
接手之后先别让现场的人走这时候的连接还是临时的，一旦断开就要对方重新点允许。请对方保持可联系，直到第三阶段验证通过。

第二阶段：配置长期访问权限

下面两种方式里凡是写“在远程电脑上”的操作：如果你已经用临时链接接手了，就由你自己在 Jump 窗口里完成；否则由现场的人完成。

先选一种方式，只做一种授权有两种方式，不用两种都做。
  • 个人使用，或公司没有 Jump 团队：用方式一。
  • 公司已经有 Jump 团队：用方式二，主要由管理员操作。

方式一：使用个人 Connect Code

简单说：你拿到一串代码，在远程电脑上输入，就完成授权。

  1. 在自己的电脑上：登录 Jump Dashboard，在 Home 页的 Your Connect Codes 里复制自己的 Connect Code。如果没有，就创建一个 Personal Connect Code。
  2. 如果远程电脑旁边是别人，把这串代码和你的账号名称发给对方。
  3. 在远程电脑上：打开 Connect → Add a remote access user → 进入浏览器登录入口 → Give remote access to someone else，输入这串代码。
  4. 在远程电脑上：核对页面上显示的账号名称是不是对的，然后点 Allow。如果页面要求先登录，现场的人用自己获准使用的 Jump 账号登录即可，不需要向使用者索要 Jump 密码。
  5. 两边一起确认：Connect 里出现了被授权的用户；在自己电脑的 Jump Desktop 用同一个账号登录后，能看到这台远程电脑。

方式二：公司已经有 Jump 团队

  1. 管理员：把远程电脑加入公司现有团队，并把你的账号加入“允许访问这台电脑”的 Access Group（访问组）。
  2. 你：接受团队邀请。
  3. 你：在 Jump Desktop 里登录被授权的账号，等电脑出现在列表里。
列表里没有远程电脑？加入团队不代表自动能连所有电脑。请管理员检查访问组和远程访问席位。不要自己新建团队，也不要把已经在公司团队里的电脑移走。
两种 Connect Code 的区别
  • 团队的 Connect Code：用来把一台电脑加入团队。
  • 个人的 Connect Code：用来给某一个人开远程访问权限。
两者用途不同，发代码时应该写明是哪一种。

第三阶段：从电脑列表重新连接，验证无人值守

1连接并输入 Mac 的系统密码

  1. 如果你是用临时链接连上的，先断开这次临时连接。
  2. 打开自己电脑的 Jump Desktop，确认电脑列表里已经出现远程电脑，点击它。
  3. 如果弹出用户名和密码，输入远程电脑的系统用户名和密码（不是 Jump 账号）。

不知道 Mac 的用户名？在远程电脑的 Terminal 里输入 whoami 再按回车，显示出来的就是用户名。

最常见的错误Jump 登录账号和 Mac 系统账号是两套账号。不要把 Jump 邮箱填成 Mac 用户名。分不清的话，回看四套账号密码别混。

2确认“看得见”也“动得了”

  1. 看 Jump 窗口的标题，确认连的是你要的那台电脑。
  2. 移动鼠标，打开一个普通窗口，输入几个字。
  3. 画面正常、键盘能打字，就说明没问题。

如果每次连接都还要现场的人点批准，请检查：长期访问用户有没有加上、Remote Desktop 等权限有没有打开、团队策略是否允许。

远程电脑 · Terminal

情况 B：

远程电脑 · Terminal · 情况 B

回车之后，按终端的提示操作：

  1. 出现 New daemon password 之类的提示时，直接用键盘输入新密码，然后按回车。
  2. 如果要求确认，再输入一次，按回车。

情况 A：

远程电脑 · Terminal · 情况 A

情况 B：

补充说明（一般用不到）：默认配置文件在 ~/.paseo/config.json，里面保存的是密码哈希，不是密码原文。如果使用了自定义的 PASEO_HOME，设置密码和重启必须针对同一个实例。

这个密码能做什么、不能做什么
  • 它是这台主机的共享访问密码，所有使用者用同一个，不是每人一个独立账号。
  • 它不会按项目隐藏操作记录，能进来的人都看得到。
  • 配对链接和密码只发给获得授权的使用者。

✓ 完成标准密码保存成功，服务重启成功。密码是否真的生效，会在第 7 步配对时一起验证。

配对链接是什么：一串网址。把它粘贴进你浏览器里的 Paseo，浏览器就能连上这台主机。

询问是否启用 Relay？新装的 Paseo 通常还没有启用 Relay。配对时如果询问是否启用，先确认是你要的那台电脑，再开启。开启后才能使用 Relay 配对入口，让不在同一网络的浏览器连上来。

2复制配对链接

  1. 等二维码和配对链接加载出来。
  2. 点 Copy（复制），拿到完整链接。

用手机的话，也可以按页面提示直接扫描二维码。

3把链接带到自己的电脑上

  • 自己用：通过私密的方式把链接传到自己的电脑上。
  • 给别的使用者用：通过私密渠道把完整链接发给对方，密码另外单独告知。
不要公开配对链接里包含连接所需的信息，要当作密码一样保管。不要把配对链接、二维码、密码或 Claude 登录凭据放进公共文档、群公告或代码仓库。
有不止一台远程电脑？
  • 每台电脑有自己的配对链接，只对应它自己。不要用同一条链接给两台电脑建入口。
  • 浏览器可以同时保存多台主机，但每次切换前要先确认主机名称。

✓ 完成标准已经拿到这台主机的完整配对链接，并且知道它的访问密码。

在自己的浏览器完成配对

需要准备：第 6 步拿到的配对链接，以及第 5 步设置的 Paseo 访问密码。

1打开 Paseo 网页

在自己的电脑用浏览器打开 https://app.paseo.sh/。

建议固定用一个浏览器配对信息保存在浏览器里。固定用同一个浏览器（以及同一个用户配置），可以避免换了浏览器又要重新配对。

2添加主机

  1. 打开 Hosts（主机）入口。
  2. 点 Add host（添加主机）。
  3. 在“粘贴配对链接”的窗口里，粘贴完整的配对链接。
  4. 点 Pair（配对）。

另一种方法：直接在浏览器里打开配对链接，按页面提示继续。

3输入 Paseo 密码

如果出现 Password 或要求输入密码，输入这台主机的 Paseo 访问密码。

这个密码和 Jump 账号密码、Mac 系统密码、Claude 密码都不一样。不同版本的页面提示文字可能略有不同。

找不到输入密码的地方？
  1. “粘贴配对链接”的第一个窗口可能只有一个链接栏。不要把密码填进链接栏。
  2. 先提交完整的配对链接，再看下一步的提示。
  3. 如果主机已经添加，但提示 Password required 又没有输入框：按页面要求，从当前浏览器里移除这个 Host，再用原来的配对链接重新添加。
“移除 Host” 安全吗？
  • 只是移除当前浏览器里保存的连接，不会删除远程电脑上的项目。
  • 不要去删除远程电脑上的 Paseo 配置。
  • 重新配对后，你在浏览器里设置过的自定义标签可能需要重新设置。
  • 不要为了绕过这个问题而关闭密码保护。

4给主机起个好认的名字

在 Host 概览里，点名称旁边的编辑标签，改成一眼能认出来的名字，例如“办公室 Mac”。默认显示的通常是那台电脑的系统名称。有多台远程电脑时，这一步尤其重要。

这是你以后每天都会用到的一步。顺序是：选主机 → 选项目 → 开工作区 → 选 Claude → 说清任务 → 检查结果。

1先选主机，再选项目

  1. 先确认当前的 Host 是你要的那台电脑。
  2. 再打开侧边栏的 Project（项目）。

记住：这里选的目录是远程电脑上的目录，不是你自己电脑上的。有多台主机时，建议把项目标签命名成“主机名 | 项目名”；遇到同名项目，要看它的 Host 徽章和实际目录来区分。

2打开或新建工作区

  • 继续之前的任务：打开对应的 Workspace（工作区）。
  • 开始新任务：用该项目的“新建 Workspace”入口。

如果任务需要独立分支：要实际确认这个工作区有没有创建 Git worktree，以及当前的目录和分支是什么。不要只看名字就下判断。

3选择 Claude 和模型

  1. 打开 Agent 会话。
  2. provider 选择 Claude。
  3. 在模型选择器里，选一个当前账号实际可用的模型。

列表里有哪些模型，取决于远程电脑上 Claude Code 的版本、账号和服务状态，会随时间变化，所以手册里不写死具体型号。

4把任务说清楚

给 Claude 的任务说明里，最好包含这四样：

  • 哪个项目
  • 以哪个分支为基准
  • 改动范围是什么
  • 希望最后产出什么
涉及真钱、真账号时如果任务涉及真实付款、真实账号，或者有无法自动完成的验证，要明确要求 Claude 停下来，告诉你需要人工做哪些步骤。

5检查结果

  • Claude 说“完成了”，不等于真机测试通过了。一定要看它给出的证据。

以后每天怎么用

平时：只需要浏览器

  1. 在自己的电脑打开 https://app.paseo.sh/（用配对时的那个浏览器）。
  2. 确认主机显示 Online。
  3. 选项目，打开工作区，给 Claude 派任务。详细做法见第 8 步。

什么时候才需要打开 Jump

  • Paseo 显示离线或连不上，需要上去看看远程电脑怎么了。
  • Claude 报错，需要到远程电脑的 Terminal 里检查。
  • 要安装或更新软件、修改 Paseo 密码、获取新的配对链接。

用 Jump 连接的方法：打开 Jump Desktop → 登录 → 在电脑列表里点远程电脑 → 如果要求用户名密码，输入远程电脑的系统账号。也可以用浏览器打开 https://app.jumpdesktop.com/；网页入口能不能直接控制电脑，取决于当前的账号、套餐和页面提示。

换了电脑，或在另一个地方想继续用

在另一台电脑或新的浏览器配置里，把第 7 步重新做一遍即可。每个浏览器通常都要单独配对一次。

不要复制别人的浏览器配置、登录文件或 Claude 凭据。

远程电脑要一直保持的状态

  • 开机、插电、联网。
  • 不休眠（显示器熄屏没关系）；笔记本不要合盖。
  • Paseo 保持运行，不要退出。

这一节讲怎样避免“两个人改同一个文件夹”和“用错账号提交代码”。

共用电脑的四条约定

  • 操作 Jump 桌面前，先和正在使用的人打声招呼，避免两个人同时抢鼠标键盘。
  • 开始任务前先检查有没有未提交的改动。不要清理别人的工作区。
  • 重启电脑、重启 Paseo 或更换 Claude 登录账号之前，先确认没有任务正在运行。
  • 使用公司批准的 Claude 账号和授权方式。Paseo 不会改变账号本身的使用条款和额度。

一个任务一个工作区

  • 代码建议统一放在 ~/Developer/ 下面。
  • 不同人员或用途，使用清晰的项目标签。
  • 多人同时改同一个仓库时，每人用自己的分支和 worktree。
不要这样做不要两个人同时在同一个工作目录里切换分支，或同时执行会改动文件的任务。

目录可以这样组织（只是建议）：

目录示例
~/Developer/<项目一>
~/Developer/<项目二>
~/Developer/worktrees/<项目>-<负责人>-<任务>

分开文件夹 ≠ 别人看不到

不同的文件夹和 worktree 可以减少文件冲突和分支冲突，但不是权限隔离：

  • 在同一个 macOS 用户下，Paseo 和 Claude 通常能访问这个用户可以读到的其他项目。
  • 共用同一台主机的人，也可能看到彼此的会话。
  • Paseo 密码是所有人共用的，不能用来区分“谁能看什么”。

如果确实要求“某些人不能看到某个项目或操作记录”，需要另外部署独立的系统用户与服务，或者使用独立的主机。不要把公共的 Paseo 当作私密项目空间。

提交代码时，“署名”和“实际账号”是两回事

项目决定什么由什么决定
Git 提交身份commit 上显示的姓名和邮箱（署名）user.name 和 user.email
GitHub 操作账号push、拉取仓库、PR 评论实际用的是谁的账号实际使用的 SSH 密钥、令牌或 gh 登录身份

所以只改 user.name，并不能防止“评论是用错误的账号发出去的”。两样都要检查。

在当前项目的终端里执行下面四条命令，可以看到这两样现在分别是什么：

远程电脑 · Terminal
git config --show-origin --get user.name
git config --show-origin --get user.email
git remote -v
gh auth status
命令它告诉你什么
前两条 git config提交时署名的姓名和邮箱，以及这个设置写在哪个文件里
git remote -v这个项目连接的是哪个远程仓库
gh auth statusgh 工具当前登录的是哪个 GitHub 账号

还要多查一步：push 实际用的是哪个账号。gh auth status 只说明 gh 工具登录的是谁，不能证明 git push 用的也是同一个账号。请看 git remote -v 显示的地址：

  • 地址以 git@ 开头（SSH 方式）：git@ 后面、冒号前面的那一段，是 SSH 主机或别名，例如 github.com。把它填进下面的命令再执行。返回 “Hi 用户名! You've successfully authenticated…” 里的用户名，就是 push 实际使用的账号。
  • 地址以 https:// 开头：push 用的是这台电脑保存的 HTTPS 凭据，不一定和 gh 登录的账号相同。拿不准时请管理员确认。
远程电脑 · Terminal · 把尖括号部分换成实际的主机或别名
ssh -T git@<SSH 主机或别名>

如果项目单独配置了 SSH 命令或密钥，实际身份以项目配置为准，这种情况请管理员帮忙确认。参考：GitHub 官方的 SSH 连接测试说明。

共用电脑上要特别小心
  • 不要把令牌或私钥发给别人。
  • 不要随意执行 gh auth switch。它会影响同一个系统用户下、共用同一份 gh 配置的其他项目，可能连带影响到别人。使用独立 gh 配置目录或环境变量令牌的项目，结果可能不同。
  • 正确做法：由管理员为每个项目配置对应的 SSH 别名，以及独立的 gh 配置目录或启动环境。

先在下面的表里找到你遇到的现象，再点开对应的问题，按顺序一项一项检查。

点击下面的问题可以展开详细步骤：

Jump 看不到电脑或连接不上

按顺序检查：

  1. 登录的 Jump 账号对不对。
  2. 这个账号有没有这台电脑的访问权限（回看第 3 步）。
  3. 团队套餐或席位状态是否正常。
  4. 远程电脑有没有电、有没有网络。
  5. Connect 是否在运行、系统权限是否完整。

不要只因为连接失败，就认定是需要续费。

如果远程电脑关机或重启后，停在 FileVault 解锁界面，可能需要现场的人完成开机和登录。另外，显示器熄屏和电脑休眠不一样：熄屏没有影响，休眠或断网才会导致连不上。

Jump 能看到桌面 但鼠标键盘动不了

通常是远程电脑只开了“屏幕录制”，没有开“辅助功能”权限。在远程电脑上点 Connect 的齿轮图标 → Diagnostics → Check macOS Permissions，按第 1 步的权限表重新检查。

Paseo 离线或一直 Connecting
  1. 先通过 Jump 连上去，检查远程电脑是否在线、Paseo 是否在运行。电脑重启过的话，Paseo 可能没有自动打开，从 Applications 手动打开它。
  2. 再看 Host 和 Relay 的状态。

Jump 正常，不代表 Paseo 一定正常，这是两个独立的东西。

需要重启服务时，先确认当前的任务状态。不要随手点“重启并关闭终端”，那样会中断其他人正在进行的工作。

提示 Password required 或密码错误
  • 确认用的是这台主机的 Paseo 密码，不是 Jump、Mac 或 Claude 的密码。有多台主机时，每台的密码不同。
  • 主机已经添加，但没有输入密码的地方：按第 7 步的方法移除后重新添加。
  • 忘记密码或想修改密码：在远程电脑上按第 5 步重新设置，保存后重启服务，再通知使用者用新密码连接。
没有模型可选 或 Claude 显示错误
  1. 先点开 provider 的错误详情，看具体写了什么。
  2. 在运行 Paseo 服务的同一个 Mac 用户下，打开 Terminal 执行 claude --version。
  3. 再执行 claude 启动它，确认能正常回复。
  4. 如果终端里也不行，依次排查：账号授权、网络、Paseo 查找 CLI 的路径。
  5. 终端里正常之后，再考虑重启 Paseo。

不要反复退出并登录别人的 Claude 账号。

在自己电脑上装了 Paseo 却没有模型

先想清楚要做的是哪一种：

  • 想连接远程电脑：只需要在浏览器里配对那台 Host，自己的电脑不用装 Paseo，也不用装 Claude。
  • 想把自己的电脑当作 Host：必须在自己的电脑上安装并登录 Claude Code。

只安装 Paseo，不会自动获得模型服务。

项目不见了 或结果出现在另一台电脑

逐项核对：Host（哪台主机）→ Project（哪个项目）→ Workspace（哪个工作区）→ 实际路径 → 分支。

多个 Host 的项目可能同时出现在侧边栏里。名字相似，不能证明是同一个目录。

不要为了找项目而重置配置。

向别人求助时附这些信息

把下面这些一次说清楚，对方能更快帮你解决：

  • 是哪台主机
  • 问题发生的时间
  • 页面上的错误原文
  • 通过 Jump 能不能连上
  • Claude 在终端里能不能用
  • 相关截图
